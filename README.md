## Getting Started

### Clone Repository

```bash
git clone https://github.com/rachitsethii/rachit-sethi-portfolio.git
cd rachit-sethi-portfolio
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

The development server will start locally and provide a URL in the terminal.

### Build for Production

```bash
npm run build
```

## Deployment

The portfolio is deployed using **Cloudflare** and connected to the GitHub repository.

Every update pushed to the `main` branch can trigger a new Cloudflare deployment.
